# Flood-risk model artifacts

No approved TensorFlow artifact or risk policy exists. This directory is empty
by design and ignores generated contents.

A future artifact bundle must be acquired from Phase 7C's governed training and
evaluation process. It must never be generated by the inference service. The
configured `.keras` file, model manifest, optional preprocessing artifact, and
risk-policy document must all remain within this directory (or the production
deployment's explicitly configured artifact root).

The model manifest contract is documented at
`../service/schemas/model-artifact-manifest.schema.json`. It requires, at
minimum:

- immutable model and feature-schema versions;
- training dataset hash and training time;
- TensorFlow and Python versions;
- artifact filename and SHA-256 checksum;
- explicit inference approval and validation status;
- threshold-policy version;
- input shape/output semantics and limitations.

The risk policy is a separate approved artifact. Its schema is documented at
`../service/schemas/risk-policy.schema.json`. No risk thresholds or example
policy values are stored in the repository.

If a future model uses an external fitted scaler, its contract is documented at
`../service/schemas/preprocessing-artifact.schema.json`. No fitted statistics
or preprocessing instance is stored here.

Never place a random, fixture-trained, or demonstration model here. A missing
bundle must remain `MODEL_NOT_AVAILABLE`.
